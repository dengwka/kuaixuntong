# 2. X (Twitter) 平台订阅接入、免登录 Syndication 架构与双通道翻译流水线

Date: 2026-10-22

## 状态
已采纳 (Accepted)

## 背景 (Context)
1. **突发情报外延诉求**：金融交易、科技创投与宏观决策高度依赖海外关键人物（如 Elon Musk、Vitalik、美联储主要官员、顶级科技大厂官方号）的第一手突发言论与动向，传统二次搬运媒体存在数分钟至数小时的延迟。
2. **X 官方 API 与 Cookie 门槛困境**：
   - X 官方开放平台已全面收紧，基础读取权限成本高昂（$100~$5000/月），不适合面向普通用户的桌面客户端；
   - 提取个人用户 Cookie (`auth_token` / `ct0`) 操作门槛过高，容易遭遇账号安全风控或失效。
3. **多语言阅读障碍**：海外博主绝大多数采用英语或其他外语发布推文，直推原文对于国内用户存在阅读门槛，亟需精准无缝的自动中文翻译。
4. **低价值互动噪音**：高频活跃大V每天产生大量日常互动回复（Replies），若不加区分地全量推送，将导致极其严重的桌面弹窗疲劳。

## 决策 (Decision)
1. **数据采集管道：官方 Syndication 免登录轻量协议 (`fetcherX.js`)**：
   - 底层采用经过实测验证的 X 官方 CDN Syndication Timeline 协议（`https://syndication.twitter.com/srv/timeline-profile/screen-name/{screenName}`）。
   - **零门槛免登录**：客户端无需配置任何 X 账号、Cookie 或付费 API Key，输入用户名即可秒级解析其真实昵称、高清头像与最新推文 JSON 拓扑。
   - 复用客户端内建代理机制，保障国内网络环境顺畅访问。
2. **博主档案预检与卡片式多订阅管理**：
   - 设置中心新增「𝕏 监控」子模块，支持输入任意用户名（如 `elonmusk`）；
   - 点击【验证】时实时向 Syndication 管道发起轻量预检，前端动态渲染博主圆形头像、真实姓名及最近推文摘要，避免拼写错误导致无效监听；
   - 支持多博主独立卡片管理，每个账号均可单独启停或移除。
3. **推文类型分级过滤机制**：
   - 默认放行**原创推文 (Original Tweets)** 与**转发/引用推文 (Retweets / Quotes)**；
   - 默认屏蔽博主对他人的简短**评论回复 (Replies)**，并在配置中保留“包含互动回复”的高级开关供用户自选。
4. **双通道智能翻译流水线 (`translator.js`)**：
   - 优先复用系统内已集成的 `DeepSeek-V3` / 智谱 `GLM-4` 模型，执行上下文感知的地道中文翻译，保留金融缩写与专有名词；
   - 在用户未配置大模型 Key 或遇到超时熔断（6 秒）时，无缝回退至免 Key 的轻量基础翻译管道，保证 100% 弹出可用；
   - 弹窗采用“中文译文（主体）+ 原推文（悬浮/折叠查看）”双语设计。
5. **专属弹窗视觉与一键穿透**：
   - 弹窗顶部标明专属 `𝕏` 标识、博主头像缩略图与姓名；
   - 点击通知卡片或外链按钮，直接调用系统默认浏览器唤起该推文在 X 平台的真实 URL。
6. **风控防御与三级冗余采集矩阵**：
   - **请求特征拟真与随机抖动 (Jitter)**：在每个订阅账号轮询周期（默认 30 秒）注入 ±15% 随机毫秒抖动，配合动态桌面 Chrome 请求指纹，消除机械爬虫定时特征；
   - **精确退避与熔断冷却**：遭遇 HTTP 429 频控时，优先解析 `x-rate-limit-reset` 时间戳执行精确休眠；无标头时按 30s ➔ 60s ➔ 120s 指数退避；
   - **三级通道冗余矩阵**：以零门槛官方 Syndication 管道为主通道，支持备用镜像探活，并在设置面板预留私有 Cookie (`auth_token`) 选填扩展槽位；
   - **单账号故障域隔离**：每个订阅账号维护独立健康度状态机，单点受限静默降级，不波及其他大V账号的轮询。

## 影响 (Consequences)
- **优点**：彻底打破海外核心大V言论的时滞壁垒；零门槛免登录保证了极佳的用户体验与系统稳定性；大模型翻译与噪音过滤保证了推文的高信噪比。
- **权衡**：多账号订阅时将按独立周期（如 30~60 秒）轮询，系统需维护分批退避与内存去重集合以保证低资源占用。
