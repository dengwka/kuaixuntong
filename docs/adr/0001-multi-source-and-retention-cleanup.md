# 1. 多数据源扩展、金十官方重要性深度对齐与存储自清理策略

Date: 2026-10-21

## 状态
已采纳 (Accepted)

## 背景 (Context)
1. **金十重点消息漏报分析**：此前设置中心中“启用快讯流”和“只看重要”为分离的复选框，用户关闭前者仅保留后者时，底层直接断流跳过请求，导致诸如深度头条（`type: 2`）或专栏重点快讯无法推送。另外，金十官方前端根据 `er(e)` 规则（`1 === e.type ? (e.data && e.data.star >= 3) : !!e.important`）进行判定，并在 API 入参中支持 `important=1` 过滤。
2. **多数据源诉求**：用户需要拓展财经证券（雪球）与科技职场爆料（脉脉“职言”），补充宏观快讯以外的一线商业与二级市场敏捷情报。
3. **磁盘与数据膨胀**：随着 7x24 小时高频轮询，`pushed_history.json` 和 `app_runtime.log` 长期累积可能占用过多磁盘空间，亟需可配置的双维度（时间+体积）定时自清理策略。

## 决策 (Decision)
1. **设置中心 UI 防呆与金十抓取重构**：
   - 将金十快讯设置重构为主开关与单选联动，只要用户选择“只看重要”，系统自动保证底层抓取管道畅通，彻底杜绝逻辑断流。
   - 请求金十 API 时增加 `important=1` 入参，本地严格按照金十官方 `er(e)` 规则放行，全面支持 `type: 0`（常规快讯）、`type: 1`（三星及以上宏观数据）、`type: 2`（深度头条与专栏文章）。
2. **扩展雪球数据源 (`fetcherXueqiu.js`)**：
   - 抓取雪球 7x24 敏捷快讯流（自动维护基础会话 Cookie），支持加精标红识别，弹窗标识为 `❄️ 雪球快讯`。
3. **扩展脉脉职言数据源 (`fetcherMaimai.js`)**：
   - 抓取公开科技企业职场与商业爆料精选流，支持可选的用户授权 Cookie，弹窗标识为 `💼 脉脉职言`。
4. **日志与数据定时自动清理机制 (`cleaner.js`)**：
   - 支持在配置中定义保留天数（默认 3 天）和单文件大小限制（默认 10MB）。
   - 每次程序启动时以及后台运行每 6 小时自动执行一次安全修剪，同时在设置面板提供“🧹 立即清理历史数据与日志”按钮。

## 影响 (Consequences)
- 优点：杜绝快讯漏报与断流隐患，资讯丰富度从宏观延伸至二级市场与一线商业动态；本地存储永远保持轻盈受控。
- 权衡：新增雪球与脉脉轮询会增加轻微的后台请求，通过合理的分批轮询间隔（10~15秒）与内存去重集合保证资源消耗可忽略不计。
